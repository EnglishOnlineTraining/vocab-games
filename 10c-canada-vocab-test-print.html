Canada — Vocabulary Test · printable papers (teacher)

Every paper gets its own version code, and the code decides which words are on it, so the same code always gives the same paper and key. Codes run A-01, A-02 …; use another set letter (B, C …) for a different group or a resit. Each paper is one double-sided sheet: Section A on the front, B and C on the back.

LRS papers (A-L01 …) use Verdana, larger text and more room, on two sheets. Their keys say spelling is not assessed.
