AReading: Choosing a Server for the Branch Office
Read the internal recommendation, then choose the correct answer for each question.

Below is a summary of the two server options for the new branch office.

Option A is a tower server with a 12-core CPU, 64 GB of RAM and two 2 TB SSDs configured as RAID 1. Because the drives are mirrored, the system keeps running even if one disk fails. Option B is a rack server with the same CPU but 128 GB of RAM, which is better if we plan to run several virtual machines.

For the network, all workstations are connected to a central switch, and the switch is connected to the router, which manages traffic between our LAN and the internet. A hardware firewall is installed between the router and the internet connection to filter incoming traffic. The current bandwidth (250 Mbit/s) is sufficient, but the contract can be upgraded. My recommendation is Option B: virtualisation will save us money in the long term. — T. Krüger
