   (grep, 2026-11-23). Open-content directories ask for the licence and a credit line. Give it in every

   A visible licence line on pages is a site-wide template change, so it waits for the Tier 19.1 pause.
2. **Which URL.** Link to a specific exercise or hub, not the homepage (Tier 19.3). URLs below were
   checked to exist in the repo; each starts with https://activities.englishonline.training/.
3. **Ask before each one:** the account and the first submission are Shaun's (rule 7).
