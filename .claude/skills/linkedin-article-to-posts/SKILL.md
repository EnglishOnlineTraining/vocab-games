# LinkedIn: article to posts

Use this skill when the user has a LinkedIn article and wants posts that promote it, or wants to plan the next article from post results.

## Workflow

1. **Confirm the anchor article.** Ask for the article text or link. It must be a strong, citation-worthy piece on one topic.
2. **Pick three to five ideas.** Each idea must come from the article: one idea, one statistic, or one framework per post. Do not repeat the same point twice.
3. **Draft each post.** Give each post:
   - A hook in the first line.
   - One idea, in short sentences.
   - A link line pointing to the article (placeholder if not yet published).
   - A one-line question or call to reply, if it fits.
4. **Plan a test order.** Suggest which post to publish first and why. Start with the idea the user is least sure about, so the test shows the most.
5. **Log results.** After posts go live, record for each post: date, idea, impressions, comments, reposts, and clicks. Use a simple table.
6. **Feed back.** Name the two or three ideas that got the most engagement. Suggest which of them should become the focus of the next article.

## Output rules

- Use plain English. Short sentences. One idea per sentence.
- Keep each post under 200 words unless the user asks for longer.
- Do not invent statistics. Use only figures from the article or from the user.
- Do not promise reach or engagement numbers.
- Ask one question at a time if details are missing.

## Results table

|------|-----------|-------------|----------|---------|--------|-------|

Keep the table in the user's Google Drive project folder, or in a chat reply if the user does not need a file.
