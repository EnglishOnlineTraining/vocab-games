💡 If-clause Type 1 — how it works Use if-clauses type 1 for things that are possible in the future.
If + simple present … , … will + infinitive

✅ If we go to Scotland, we will visit Edinburgh Castle.
✅ We will see the Highlands if we travel by train.

⚠️ After if, use the present simple — NOT will.

Exercise C

Writing – A Short Biography

Write a short biography (60–80 words) about Alexander Graham Bell. Use the fact file and sentence starters below.

📋 Fact File: Alexander Graham Bell

🗓 Born: 3 March 1847 in Edinburgh, Scotland

👨‍👩‍👦 Family: His mother and wife were deaf

🏫 Work: Opened a school for deaf people in Boston, USA

📞 Invention: The telephone — invented in 1876

🌍 Later life: Moved to the USA; continued scientific experiments

💀 Died: 2 August 1922 in Nova Scotia, Canada

💡 Relative clauses — how to use them Use who for people: Bell was a scientist who invented the telephone.
Use which / that for things: The telephone is an invention which changed the world.
Use where for places: Edinburgh is the city where Bell was born.
