Teacher only

Tests are not listed on any year hub or in the activity index, so students reach them only by a link you send.

Do not share this URL with a class. It lists every test together with its release code. The codes are a timing gate, not security — each one is readable in its test's page source, so treat a code as "stops a class starting early", never as "keeps a determined student out". Change the code between sittings by editing RELEASE_CODE in the test file.
